# Documentation Scripts

Tools for synchronizing documentation indexes and checking metadata and links.

[Setup, commands, and maintenance guide](guide.md)

| Tool | Purpose |
| --- | --- |
| [Plan synchronization](sync-plans.py) | Organizes plans and generates active indexes. |
| [Specification synchronization](sync-specifications.py) | Generates specification indexes. |
| [Research synchronization](sync-research.py) | Generates the research index. |
| [Runbook synchronization](sync-runbooks.py) | Generates the runbook index. |
| [Link checker](check-doc-links.py) | Checks local documentation links. |
| [Staged documentation checker](check-staged-docs.py) | Checks staged documentation. |

The [tests](tests/) cover the documentation tools.
