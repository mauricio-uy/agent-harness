# Plans

Plans are organized by status. Active indexes:

- [Draft](draft/README.md): being prepared; decisions may remain open.
- [Awaiting approval](awaiting-approval/README.md): ready for human review.
- [Approved](approved/README.md): authorized and ready to start.
- [In progress](in-progress/README.md): currently being executed.

Historical plans: [completed](completed/README.md), [cancelled](cancelled/README.md), and [superseded](superseded/README.md). These directories are searchable by plan ID or filename and are excluded from active indexes.
