# Replace with the research question

## Question and scope

State the question, why it matters, constraints, exclusions, and what would constitute a useful answer. Include an effort limit only if agreed.

## Summary of findings

Summarize the answer or inconclusive result, its supporting evidence, and principal limitations.

## Evidence

| ID | Source or observation | Finding | Applicability and limitations |
| --- | --- | --- | --- |
| E1 | Link the source or recorded check; include access date | State the supported claim | Relevant version, context, and limits |

For executed checks, include the command or method, environment, date, and observed result needed to reproduce the finding. Clearly identify checks not yet run.

## Analysis and alternatives

Explain the inferences drawn from the evidence and conflicting findings. When comparing options, apply the same criteria to each. Omit the comparison if it does not apply.

## Recommendation and uncertainty

State any recommendation as a proposal, cite its evidence, and explain tradeoffs, unanswered questions, and what could change the conclusion. State explicitly if no recommendation is justified.

## Investigation checkpoint

- Completed work: Summarize what was examined and verified.
- Stopping reason: Question answered, evidence gap, human input needed, or agreed limit reached.
- Next step: State the next investigation or decision needed, or that none remains within scope.
- Recheck triggers: Identify changes that could invalidate findings, or explain why none is identified.
