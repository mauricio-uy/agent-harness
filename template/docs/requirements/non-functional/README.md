# Non-Functional Requirements

Each requirement lives in `records/` as `<ID>-<slug>.md` and never moves. Its frontmatter `status` decides which index lists it, and a status change moves only that row. Open only the index you need, or search `records/` by ID.

| Index | Contents |
| --- | --- |
| [Awaiting Approval](awaiting-approval.md) | Ready for human review; blocking questions resolved. |
| [Draft](draft.md) | Being developed; decisions and details may remain open. |
| [Approved](approved.md) | The current revision is approved. |
| [Rejected](rejected.md) | Reviewed and not adopted; kept for history. |
| [Superseded](superseded.md) | Replaced by an approved successor; kept for history. |

The indexes are generated by `harness sync`; edit the documents' frontmatter, not the rows.
