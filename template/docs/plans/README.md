# Plans

Each plan lives in `records/` as `<ID>-<slug>.md` and never moves. Its frontmatter `status` decides which index lists it, and a status change moves only that row. Open only the index you need, or search `records/` by ID.

| Index | Contents |
| --- | --- |
| [Draft](draft.md) | Being prepared; decisions may remain open. |
| [Awaiting Approval](awaiting-approval.md) | Ready for human review; blocking decisions resolved. |
| [Approved](approved.md) | The current revision is approved; implementation has not started. |
| [In Progress](in-progress.md) | Approved work is being executed. |
| [Completed](completed.md) | Implementation and planned verification are finished. |
| [Cancelled](cancelled.md) | Work was abandoned; the plan records why. |
| [Superseded](superseded.md) | Replaced by another plan, named in `superseded_by`. |

The indexes are generated by `harness sync`; edit the documents' frontmatter, not the rows.
